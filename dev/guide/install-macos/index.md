# macOS

## Voraussetzungen

|                |                                       |
| -------------- | ------------------------------------- |
| Rechner        | Mac mit Apple Silicon (M1 oder neuer) |
| Betriebssystem | macOS 13 (Ventura) oder neuer         |
| Speicherplatz  | ca. 1 GB                              |

## Installation

1. [umsatzschaetzung-osx-arm64.dmg](https://github.com/rotmanjanez/Umsatzschaetzung/releases/latest/download/umsatzschaetzung-osx-arm64.dmg) herunterladen (wer schon über die Startseite geladen hat, findet die Datei im Ordner **Downloads**).
1. Die geladene DMG-Datei öffnen.
1. Das Programmsymbol **Umsatzschätzung** in den Ordner **Programme** ziehen.
1. Das Installationslaufwerk auswerfen.

## Programm starten

Im Ordner **Programme** doppelt auf **Umsatzschätzung** klicken.
