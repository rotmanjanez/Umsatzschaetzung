# Sicherheitslücken melden

Sicherheitslücken bitte **nicht** über ein öffentliches Issue melden, sondern an

**security@amtstools.de**

Hilfreich sind eine Beschreibung der Lücke, die betroffene Version und, soweit
möglich, eine Schrittfolge zum Nachvollziehen. Eine Eingangsbestätigung kommt
innerhalb von sieben Tagen.

Das Programm ist ein Einzelprojekt ohne Bereitschaftsdienst. Zugesagt wird eine
Antwort, kein Zeitpunkt für die Behebung. Ist eine Lücke behoben, wird sie in den
Anmerkungen zur Veröffentlichung genannt; wer sie gemeldet hat, wird auf Wunsch
dort genannt.

## Unterstützte Versionen

Sicherheitskorrekturen erscheinen ausschließlich in der jeweils neuesten
Veröffentlichung. Ältere Stände werden nicht nachgepflegt.

## Geltungsbereich

Zu diesem Programm gehören die Anwendung selbst, die mitgelieferten Regeln und
Modelle sowie die Veröffentlichungen unter
<https://github.com/rotmanjanez/Umsatzschaetzung/releases>.

Die Anwendung verarbeitet ausschließlich lokal und stellt von sich aus keine
Netzwerkverbindungen her. Meldungen zu den Webseiten unter `amtstools.de` sind
ebenfalls willkommen, betreffen aber nicht die Software selbst.
