# Beispielprüfung

Diese Anleitung führt anhand eines Beispiels durch eine komplette Betriebsprüfung –
von der Installation über den Belegimport bis zur fertigen Kalkulation.

Als Datenbasis dient ein Beispieldatensatz zum Herunterladen: die
Eingangsrechnungen eines Gasthauses für ein ganzes Jahr. Eigene Belege sind dafür
nicht erforderlich.

Dauer: rund 20 Minuten.

!!! tip "Mitmachen"
    Am meisten bringt die Anleitung, wenn jeder Schritt gleich im Programm
    mitgemacht wird. Am Ende steht dann eine eigene, vollständige Prüfung.

## Vorbereitung

Vorab muss das Programm auf dem Rechner installiert sein:

[macOS](install-macos.md){ .md-button .md-button--primary }
[Windows](install-windows.md){ .md-button }

Nach der Installation geht es direkt mit [der ersten Prüfung](start.md) weiter.
