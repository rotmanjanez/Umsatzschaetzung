# Windows

## Voraussetzungen

| | |
|---|---|
| Hardware | 64-Bit-PC (x64) |
| Betriebssystem | Windows 10 (ab Version 22H2) oder Windows 11 |
| Speicherplatz | ca. 1 GB |
| Berechtigung | Administratorrechte zur Installation |

## Installation

1. [umsatzschaetzung-win-x64.msi](https://github.com/rotmanjanez/Umsatzschaetzung/releases/latest/download/umsatzschaetzung-win-x64.msi) herunterladen (wer schon über die Startseite geladen hat, findet die Datei im Ordner **Downloads**).
2. Die Installationsdatei per Doppelklick öffnen.
3. Den Lizenzvertrag annehmen und die Abfrage der Benutzerkontensteuerung für Administratorrechte bestätigen.
4. Nach Abschluss der Installation das Fenster schließen.

## Programm starten

Das Startmenü öffnen und **Umsatzschätzung** aufrufen.

!!! note "SmartScreen-Hinweis von Windows"
    Das Installationspaket ist digital signiert. Meldet Microsoft Defender SmartScreen dennoch **Der Computer wurde durch Windows geschützt**: auf **Weitere Informationen** klicken, sicherstellen, dass als Herausgeber *Janez Rotman* angegeben ist, und auf **Trotzdem ausführen** klicken.
